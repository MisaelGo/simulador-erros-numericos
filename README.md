# Simulador de Propagação de Erros Numéricos

Projeto desenvolvido em Java para a disciplina de Cálculo Numérico.

O programa simula operações aritméticas com precisão limitada, permitindo observar os efeitos de truncamento, arredondamento e propagação de erros numéricos.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Controle de dígitos significativos
- Truncamento
- Arredondamento
- Cálculo do erro absoluto
- Cálculo do erro relativo
- Testes de propagação de erros
- Cancelamento subtrativo
